# 🔗 URL-Shortener

Сервис для сокращения длинных ссылок с возможностью создания как случайных, так и пользовательских коротких кодов.  
Поддерживает регистрацию и аутентификацию пользователей, срок действия ссылок, детальную статистику переходов (включая устройства, браузеры, IP-адреса) и расширенные возможности для администраторов.

Проект написан на **Python** с использованием **FastAPI**, **PostgreSQL**, **Redis** и **Nginx**, упакован в **Docker** и готов к быстрому развёртыванию.

---

## 📋 Основные возможности

- **Сокращение ссылок** – автоматическая генерация короткого кода (алгоритм Base62) или создание собственного кастомного кода.
- **Управление сроком действия** – ссылка может быть бессрочной или истекать (по умолчанию 1 день, максимум 365 дней).
- **Статистика переходов** – для каждой ссылки сохраняются:
  - дата первого и последнего клика,
  - общее количество кликов,
  - количество переходов по дням,
  - тип устройства (мобильное/десктоп), браузер, IP-адрес.
  - для администраторов доступна агрегированная статистика по всем ссылкам.
- **Пользовательские аккаунты** – регистрация и вход (JWT-аутентификация), возможность редактировать и удалять свои ссылки.
- **Гостевой доступ** – можно создавать короткие ссылки без регистрации.
- **Кеширование** – горячие ссылки кешируются в Redis для быстрого редиректа (паттерн Cache-Aside).
- **Безопасность** – пароли хэшируются с помощью **Argon2**, JWT-токены подписываются секретным ключом.
- **Готовый API** – интерактивная документация Swagger (`/docs`) для тестирования всех эндпоинтов.

## 🧩 Особенности архитектуры

- **Асинхронная работа** – все операции с БД и Redis выполняются асинхронно (FastAPI + asyncpg + aioredis).
- **Чистая архитектура** – код разделён на слои (`api` – маршруты, `crud` – бизнес-логика, `models` – SQL-модели, `schemas` – Pydantic-схемы, `core` – конфигурация и утилиты).
- **Миграции** – выполняются автоматически при старте контейнера через `prestart.sh` (Alembic).
- **Кеширование** – реализован паттерн Cache-Aside: при запросе короткой ссылки сначала проверяется Redis, при промахе – PostgreSQL, и результат сохраняется в кеш.
- **Тестовая среда** – отдельный контейнер с тестовой БД, тесты запускаются изолированно и автоматически завершаются.

## 🚀 Быстрый старт

### Требования
- Docker и Docker Compose (рекомендуется)
- (Опционально) Python 3.13+ и Poetry для локального запуска без Docker

### Переменные окружения

Создайте файл `.env` в корне проекта со следующим содержанием (пример):

```env
APP_CONFIG__DB__URL=postgresql+asyncpg://user:password@pg:5432/shortener
APP_CONFIG__JWT__JWT_SECRET_KEY=ваш_секретный_ключ
APP_CONFIG__RDS__REDIS_URL=redis://redis:6379/0
```

### Запуск через Docker (рекомендованный способ)

Клонируйте репозиторий:

```bash
git clone https://github.com/LiSha4202/url-shortener.git
cd url-shortener
```

Запустите все сервисы:

```bash
docker-compose up -d
```

При первом запуске автоматически:
- установятся зависимости через Poetry,
- применятся миграции Alembic,
- поднимутся PostgreSQL, Redis, Nginx и само приложение.

Приложение будет доступно по адресу: [http://localhost](http://localhost) (Nginx проксирует на FastAPI).

Интерактивная документация API: [http://localhost/docs](http://localhost/docs)

# 📡 API Документация
После запуска сервиса документация доступна по адресу:
http://localhost/docs (или /redoc для альтернативного стиля).

# Основные эндпоинты:
| Метод     | Путь                             | Описание                                                                     |
|-----------|----------------------------------|------------------------------------------------------------------------------|
| **POST**  | /auth/register                   | Регистрация нового пользователя                                              |
| **POST**  | /auth/login                      | Вход и получение JWT-токена, set-Cookie                                      |
| **POST**  | /auth/logout                     | Выход и удаление Cookie                                                      |
| **PATCH** | /auth/update                     | Обновление данных пользователя (Имя, почта, пароль)                          |
| **GET**   | /auth/me                         | Вывод данных пользователя                                                    |
| **DELETE**| /auth/delete                     | Удаление пользователя                                                        |
|           |                                  |                                                                              |
| **POST**  | /links/create                    | Создание короткой ссылки (гость или авториз.)                                |
| **PATCH** | /links/{short_code}/update       | Изменение данных ссылки (Оригинальная ссылка, срок жизни)                    |
| **DELETE**| /links/{short_code}/delete       | Удаление ссылки                                                              |
| **GET**   | /links/{short_code}/stats        | Статистика по конкретной ссылке                                              |
| **GET**   | /links/stats/all                 | Общая статистика по всем ссылкам (количество переходов, общие данные ссылок) |
| **GET**   | /links/stats/top                 | Топ-10 популярных ссылок (По количеству переходов, от большего к меньшему)   |
| **GET**   | /links/{}/my_links               | Все ссылки, принадлежашие пользователю                                       |
| **GET**   | /links/{short_code}/stats/detail | Подробная статистика о переходах по ссылке (Устройство, Браузер, IP)         |
| **GET**   | /links/stats/delete_cache        | Очистка кэша для обновления глобальной статистики                            |
|           |                                  |                                                                              |
| **GET**   | /{short_code}                    | Редирект по оригинальной ссылке (Отсутствует в схемах в /docs)               |

### ❗ Важно
В /docs роуты обозначены замком 🔓, это значит, что требуется авторизация, кнопка авторизации находится в верхней части страницы справа,
`Зелёная кнопка [Authorize 🔓]`, в ней введите ПОЧТУ, и ПАРОЛЬ зарегистрированного пользователя, пример:
- test@example.com
- testpassword

Не влияет на создание ссылки, т.е. на роут /links/create - Create New Link, можно и без входа создавать ссылку, соответствует смыслу проекта 🙃

### 📍 После обновления данных пользователя
После обновления данных пользователя, а именно `ПОЧТА или ПАРОЛЬ`, нужно будет перелогинится, потому что данные, которые вы раннее вводили в логин, уже недействительны, потому что вы их изменили. На имя пользователя это не распространяется, т.е. если изменили только имя пользователя, не нужно перелогинится, оно не влияет на авторизацию.

### ➡️ Redirect по ссылке
При создании ссылки в ответе автоматически создаётся полная ссылка перехода по ссылке, можно перейти по ней, выделив ссылку и нажав на появившуюся кнопку *Перейти* (на примере Yandex Browser), либо можно ввести вручную в строке поиска браузера:
`http://localhost/{short_code вашей ссылки}` - Далее происходит редирект по ссылке, пример - `http://localhost/examplecode`

### ⏲️ Бессрочная ссылка
Во премя создания ссылки автоматически подставляется срок жизни `"expires_at": 1`, это значит что ссылка будет "жить" один день, чтобы сделать её бессрочной, достаточно удалить строку `"expires_at": 1`, т.е.:
```json
  Было:   
  {                                                 
  "original_url": "https://example.com/",                 
  "short_code": "g9QN_1NNslfm2v",                         
  "expires_at": 1                          
  }
```
```json
  Стало:
  {
  "original_url": "https://example.com/",
  "short_code": "g9QN_1NNslfm2v"  **<-- запятую тоже нужно удалить**
  }
```

### 🧪 Тестирование
Тесты разделены на три категории и запускаются автоматически в изолированном контейнере.

Unit-тесты – проверка хеширования, генерации токенов, Base62 и прочих утилит.

Интеграционные тесты – тестирование CRUD-операций с реальной БД (используется тестовая БД).

E2E-тесты – полные сценарии работы с API (создание ссылки, редирект, статистика).

После завершения тестов тестовый контейнер автоматически останавливается.
